# Журнал технических решений

| № | Решение | Причина | Альтернативы |
|---|---|---|---|
| D-01 | Next.js 15.5 (App Router), а не 16.x | 15.5 — зрелая ветка с долгосрочными исправлениями; в 16.x изменены соглашения (middleware → proxy и др.), что повышает риск для срока хакатона | Next 16.4 |
| D-02 | React 19.2, React Three Fiber 9, drei 10, three 0.180 | R3F 9 требует React 19; версии совместимы по peer-зависимостям | — |
| D-03 | Prisma 6.19 + SQLite | Стабильная ветка (latest-тег Prisma указывает на 8.0.0-rc); SQLite не требует сервера для демонстрации | Prisma 7 (обязательные driver adapters), PostgreSQL |
| D-04 | Перечисления хранятся строками, проверка — Zod | Переносимость схемы между SQLite и PostgreSQL | Prisma enum |
| D-05 | Параметры участков — отдельная таблица с типизированными столбцами, а не EAV `ScenarioParameter` | Строгая типизация, ограничения уникальности (scenarioId, stationId) | EAV «ключ-значение» |
| D-06 | Метрики прогонов — EAV (`AggregateMetric`, `StationMetric`) | Каталог метрик расширяется без миграций; ключи проверяются кодом | Широкие таблицы |
| D-07 | Журнал событий — один JSON на прогон | Читается только целиком; объём ~1,5 тыс. событий; запись одной строкой быстрее | Таблица `SimulationEvent` построчно |
| D-08 | Собственные UI-компоненты на Tailwind вместо shadcn/ui CLI | Меньше зависимостей и генерируемого кода; все компоненты доступны с клавиатуры | shadcn/ui |
| D-09 | Собственная сессия (jose + bcryptjs + таблица Session) вместо NextAuth | Простая базовая авторизация по логину; возможность отзыва; без внешних провайдеров | Auth.js |
| D-10 | Ресурсы оплачиваются за доступность (вместимость × горизонт × ставка) | Персонал и оборудование оплачиваются за смену; добавление ресурса честно увеличивает затраты | Оплата только занятого времени |
| D-11 | Материалы учитываются при запуске задания; расходники — при начале операции | Компоненты выдаются со склада при запуске; изделия в НЗП тоже потребляют материалы | Учёт только при выпуске |
| D-12 | Базовый сценарий защищён от изменения параметров и удаления | Точка отсчёта для сравнения должна быть стабильной | — |
| D-13 | Состояние 3D в режиме воспроизведения — кадры с шагом 5 мин из журнала событий | Дешевле, чем синхронизация сотен объектов; отражает только рассчитанное состояние | Интерполяция движения изделий |
| D-14 | Очереди в 3D рисуются тремя InstancedMesh на всю сцену | Константное число draw calls независимо от длины очередей | Компонент на изделие |
| D-15 | Процедурная геометрия, внешние GLB — через адаптер (ASSET_MANIFEST) | Запуск без внешних файлов | Загрузка GLB по умолчанию |
| D-16 | Шрифт Golos Text через next/font | Хорошая кириллица, файлы шрифта встраиваются в сборку (скачиваются один раз при сборке) | Системные шрифты |
| D-17 | Тестовые БД (`test.db`, `e2e.db`) пересоздаются удалением файла и `prisma migrate deploy` | `prisma migrate reset` заблокирован для автоматизированных агентов; отдельные файлы не затрагивают рабочую `dev.db` | migrate reset |
| D-18 | Ограничитель частоты в памяти процесса | Достаточно для однопроцессного демо-развёртывания | Redis |
| D-19 | Сравнение — интервал Уэлча по репликациям, базовый seed одинаков у сценариев | Честная оценка различимости; общий seed даёт частично общие случайные числа (CRN) | Сравнение одиночных прогонов |
| D-20 | Палитра серий графиков проверена валидатором CVD/контраста; цвета статусов зарезервированы | Доступность и однозначность цвета | — |
| D-21 | ESLint не настроен; качество кода контролируется `tsc --strict` (+ `noUncheckedIndexedAccess`) и тестами | Экономия времени; `next lint` устарел в Next 15.5 | ESLint flat config |
