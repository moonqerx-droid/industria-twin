# Критерии приёмки INDUSTRIA TWIN

Идентификаторы требований — по [TZ.md](TZ.md); тесты — по [TEST_PLAN.md](TEST_PLAN.md).

## 1. Функциональные критерии

| ID | Критерий | Требования | Способ проверки |
|---|---|---|---|
| AC-01 | Неавторизованный пользователь перенаправляется на `/login`; API без сессии отвечает 401 | FR-01 | e2e «незалогиненный пользователь перенаправляется на вход»; интеграция «без cookie доступ к API запрещён» |
| AC-02 | Вход демо-учётными записями admin / engineer / viewer; неверный пароль — сообщение об ошибке; выход отзывает сессию | FR-01, FR-03 | e2e «неверный пароль показывает ошибку»; интеграция «выход отзывает серверную сессию» |
| AC-03 | Наблюдатель не может создавать, изменять сценарии и запускать моделирование (403, кнопки скрыты) | FR-02 | интеграция «наблюдатель не может создавать сценарии…»; e2e «наблюдатель не видит действий изменения сценария» |
| AC-04 | API модели возвращает 6 участков с идентификаторами `st-*`, граф из 10 узлов и 10 связей без висячих ссылок | FR-04 | интеграция «возвращает участки со стабильными идентификаторами и граф процесса» |
| AC-05 | Мнемосхема показывает для каждого участка название, статус, ресурс, производительность, очередь, стоимость, загрузку | FR-05 | ручная проверка `/process`; e2e «выбор участка на мнемосхеме…» |
| AC-06 | Выбор узла мнемосхемы открывает панель метрик и даёт переход к тому же участку в 3D | FR-06, FR-28 | e2e «выбор участка на мнемосхеме открывает панель и переход в 3D сохраняет выбор» |
| AC-07 | Инженер создаёт, редактирует, копирует, удаляет сценарий; изменения сохраняются в БД | FR-07, FR-08 | интеграция «инженер создаёт сценарий», «редактирует и сохраняет сценарий», «копирует сценарий», «удаляет сценарий…» |
| AC-08 | Базовый сценарий нельзя изменить по параметрам и удалить (409) | FR-09 | интеграция «базовый сценарий защищён…» |
| AC-09 | Недопустимые параметры отклоняются сервером (400) с перечнем ошибок | FR-10 | интеграция «валидация отклоняет недопустимые параметры» |
| AC-10 | Запуск моделирования выполняет R репликаций и сохраняет прогон с метриками, репликациями и журналом событий | FR-11, FR-12, FR-13 | интеграция «запускает моделирование и сохраняет результат», «журнал воспроизведения…» |
| AC-11 | Повторный запуск с теми же параметрами и seed даёт те же средние | FR-12, NFR-08 | интеграция «повторный запуск того же сценария…»; unit «один и тот же seed…» |
| AC-12 | Рассчитываются все показатели каталога (выпуск, выпуск/ч, цикл, ожидание, очередь, загрузка, НЗП, брак, доработки, стоимость, стоимость единицы); при нулевом выпуске стоимость единицы не определена | FR-14 | unit-группы «граничные случаи», «стоимость» |
| AC-13 | Дашборд показывает KPI с 95% ДИ, узкое место, таблицу участков и графики, построенные по сохранённому прогону | FR-15, FR-19, FR-20 | e2e «дашборд показывает рассчитанные KPI и узкое место» |
| AC-14 | Сравнение показывает до/после, абсолютную и относительную разность, направление, различимость, изменённые параметры и смещение узкого места | FR-16, FR-17, FR-18 | интеграция «сравнивает прогон с базовым»; e2e «инженер создаёт сценарий… и сравнивает» |
| AC-15 | 3D-сцена загружается, поддерживает вращение/масштаб, предустановленные камеры, возврат на общий план | FR-21 | e2e «3D-тур: сцена загружается…»; ручная Р-6 |
| AC-16 | Клик/касание по оборудованию или табличке выбирает участок (панель, подсветка, камера) | FR-22, FR-26, FR-28 | ручная проверка; e2e «навигация доступна и 3D-тур сохраняет маршрут и показатели» |
| AC-17 | Точки интереса показывают описание, практику и метрики выбранного прогона | FR-23 | e2e «3D-тур…» (poi-receiving), «выбор участка на мнемосхеме…» (poi-testing) |
| AC-18 | Экскурсия по маршруту из 7 остановок, вперёд/назад, автоматический режим | FR-24 | e2e «3D-тур…» |
| AC-19 | Воспроизведение прогона по кадрам из журнала событий; модельное время на шкале | FR-25 | e2e «3D-тур…» (кадр 60 → 05:00) |
| AC-20 | Число единиц оборудования в сцене равно вместимости участка в выбранном прогоне | FR-27 | ручная: сравнить `/factory?run=<базовый>` и `/factory?run=<сценарий с 3 постами>` |
| AC-21 | Без WebGL показывается 2D-план с теми же участками, выбором и метриками | FR-30 | e2e «без WebGL показывается план цеха…» |
| AC-22 | Переход «Сравнить сценарии по участку» открывает сравнение с фокусом на участке | FR-29 | ручная: панель участка → `/compare?station=…` |
| AC-23 | Администратор видит пользователей, права ролей и может удалить прогон; другие роли — нет | FR-32 | интеграция «удаляет сценарий… удаление прогонов — только admin», «список пользователей…»; e2e «администратор видит раздел администрирования» |
| AC-24 | Страница документации объясняет модель, данные, формулы, ограничения | FR-31 | ручная проверка `/documentation` |
| AC-25 | Частота запусков моделирования и попыток входа ограничена (429) | NFR-07 | интеграция «ограничивает частоту запусков моделирования», «ограничивает частоту попыток входа» |
| AC-26 | Интерфейс без горизонтальной прокрутки страницы на планшете и телефоне; навигация доступна | NFR-01 | e2e `responsive.spec.ts` (tablet, mobile) |

## 2. Критерии готовности проекта (раздел 16 исходного задания)

| № | Критерий | Способ проверки |
|---|---|---|
| Q-01 | Приложение запускается по README | Выполнить команды раздела «Быстрый старт» README на чистом клоне |
| Q-02 | Данные базы создаются и доступны | `npm run setup` выводит «Seed завершён…: пользователей 3, сценариев 5, прогонов 5» |
| Q-03 | Вход и роли работают | AC-01…AC-03 |
| Q-04 | Есть действующий процесс | AC-04, AC-05 |
| Q-05 | Симуляция выполняется реально | AC-10, AC-11; unit-тесты движка |
| Q-06 | Метрики рассчитываются | AC-12 |
| Q-07 | Сценарии сохраняются | AC-07 |
| Q-08 | Сравнение показывает результаты | AC-14 |
| Q-09 | 3D-сцена загружается | AC-15 |
| Q-10 | Объекты 3D связаны с теми же сущностями, что аналитика | AC-06, AC-16, AC-17; интеграция «состояние тура содержит метрики прогона по тем же stationId» |
| Q-11 | Навигация и точки интереса работают | AC-17, AC-18 |
| Q-12 | Основные тесты проходят | `npm run test`, `npm run test:e2e` |
| Q-13 | Выполняется TypeScript typecheck | `npm run typecheck` без ошибок |
| Q-14 | Production build завершается успешно | `npm run build` |
| Q-15 | Все обязательные артефакты первого этапа подготовлены | Наличие файлов по REQUIREMENTS_TRACEABILITY.md (TZ, BPMN, UML, ER, архитектура, макеты, план тестирования, контракт 3D-сцены, карта POI) |
| Q-16 | Демонстрация без ручного исправления данных | Ручная проверка Р-1 по DEMO_SCRIPT.md |
| Q-17 | Отсутствующие функции честно указаны в итоговом отчёте | Раздел «Известные ограничения» FINAL_REPORT.md |
