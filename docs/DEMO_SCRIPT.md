# Сценарий демонстрации (5–7 минут)

Подготовка: `npm run setup && npm run build && npm start`, вход под `engineer` (пароль в README). Все числа на экране рассчитываются симулятором; в сценарии показа нет заранее зашитых значений. Для справки перед показом выполните `npm run report:scenarios` — команда печатает актуальные результаты всех демонстрационных сценариев.

## Возможные вопросы жюри

* *Откуда цифры?* — Из симулятора, сохранённого прогона; параметры видны в сравнении и в «Документации».
* *Почему выпуск почти не растёт при добавлении ресурса?* — Выпуск ограничен входящим потоком заданий; при достаточной мощности растёт не выпуск, а сокращаются цикл и НЗП. Если ограничение смещается на другой участок, это видно в блоке «Узкое место».
* *Насколько результат надёжен?* — 20 репликаций, 95% ДИ, сравнение Уэлча; модель не учитывает поломки и переналадки (см. ограничения).
* *Что будет без WebGL?* — Открывается план цеха 2D с теми же точками интереса и показателями.
