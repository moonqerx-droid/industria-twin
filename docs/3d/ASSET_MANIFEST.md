# Манифест 3D-ассетов

Текущая версия сцены не загружает внешних файлов: вся геометрия процедурная (`src/components/factory3d/models.tsx`), текстуры напольной разметки рисуются на canvas во время выполнения. Отсутствие внешних GLB не блокирует запуск.

## Процедурные модели

| Ассет | Компонент | Состав | Где используется |
|---|---|---|---|
| Обрабатывающий центр ЧПУ | `CncMachine` | станина, кожух, смотровое окно, дверь, пульт, шпиндель, сигнальная колонна | `st-machining` |
| Сборочный пост | `AssemblyPost` | верстак, портал с талью, насос (при занятости), работник | `st-assembly` |
| Испытательный стенд | `TestBench` | рама, бак, трубопроводы, щит с манометром, насос | `st-testing` |
| Пост доработки | `ReworkPost` | верстак, инструментальный щит, шкаф | `st-rework` |
| Линия упаковки | `PackingLine` | поворотный стол, мачта, кольцо обмотчика, паллета с ящиком | `st-packing` |
| Стеллаж | `Rack` | стойки, балки, паллеты с коробками | `st-receiving` |
| Пост комплектации | `PickingStation` | стол, коробка, работник | `st-receiving` |
| Насос (изделие) | `PumpModel`, `ProductionItems` | рама, двигатель, улитка, патрубки | посты, очереди |
| Сигнальная колонна | `StackLight` | 3 секции (зелёная, янтарная, красная) | всё оборудование |
| Конвейер | `ConveyorSystem` | ролики, стойки, боковины | цех |

## Подключение внешних GLB (адаптер)

1. Положить файл в `public/models/<имя>.glb` и добавить строку в таблицу ниже (лицензия обязательна).
2. Создать компонент-адаптер с интерфейсом `EquipmentModelProps` (`kind, capacity, busy, statusColor, footprint`), загружающий модель через `useGLTF` из `@react-three/drei`, и клонирующий её `capacity` раз; занятость `busy` отражать как минимум сигнальной колонной `StackLight`.
3. В `EquipmentModel` заменить ветку нужного `kind` на адаптер, обернув его в `<Suspense fallback={процедурная модель}>`, чтобы при ошибке загрузки сцена продолжала работать.
4. Бизнес-логика, stationId, точки интереса и метрики не меняются.

| Файл | Назначение | Источник | Лицензия | Статус |
|---|---|---|---|---|
| — | — | — | — | внешние ассеты не подключены |

Записи `MediaAsset` в БД (`procedural://cam-…`) помечены `isPlaceholder = true`: это ссылки на ракурс процедурной сцены, а не на файлы.
